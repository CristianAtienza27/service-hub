# MVP Scope

## Objetivo

Construir una versión demostrable que permita completar el flujo principal de recepción y gestión de solicitudes.

## Funcionalidades incluidas

### Gestión del negocio

- Registro de un negocio.
- Inicio de sesión del propietario.
- Consulta y edición básica del perfil.
- URL pública mediante slug.

### Página pública

- Visualización del nombre del negocio.
- Descripción básica.
- Datos de contacto.
- Formulario de solicitud.

### Solicitudes

- Crear una solicitud pública.
- Listar solicitudes del negocio.
- Consultar el detalle de una solicitud.
- Cambiar el estado de una solicitud.

### Estados iniciales

- NEW
- IN_REVIEW
- NEEDS_INFO
- ACCEPTED
- REJECTED

### Multiempresa

- Cada negocio tendrá sus propios usuarios y solicitudes.
- Un usuario no podrá acceder a información de otro negocio.
- Las entidades de negocio estarán asociadas a un tenant.

## Funcionalidades no incluidas

- Agenda.
- Reservas automáticas.
- Presupuestos.
- Pagos.
- Suscripciones.
- Recordatorios.
- Correos automáticos.
- Chat.
- WhatsApp.
- Inteligencia artificial.
- Facturación.
- Roles avanzados.
- Aplicación móvil.
